# Cloudflare edge-router configuration outage

Source report: https://web.archive.org/web/20211006135542/https://blog.cloudflare.com/todays-outage-post-mortem-82515/

This corpus record is a fixed summary from the public danluu/post-mortems index.

A bad router-rule configuration caused all Cloudflare edge routers to crash, taking down
Cloudflare's service. The incident is categorized by the upstream collection as a
configuration error.
